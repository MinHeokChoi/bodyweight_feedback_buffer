# 타이머 탭 요구사항 (초안)

> 상태: 요구사항 정리 단계. 구현 전 논의용 문서입니다.
> 작성: 2026-09-12

## 1. 배경

지금까지 운동 중 시간 측정은 아이폰 기본 시계 앱의 타이머로 해왔습니다. 기능 자체는 충분했지만, 운동 과정 중에 피드백 버퍼를 함께 쓰게 되면서 두 앱을 번갈아 오가는 부담이 생겼습니다.

더 중요한 문제는 **기본 시계 앱은 시간을 남기지 않는다**는 점입니다. 타이머를 껐다 켜는 동안 "오늘 어떤 운동에 얼마를 썼는지", "이번 달에 며칠 운동을 갔는지"는 전부 사라집니다.

타이머 탭의 목적은 두 가지입니다.

1. 운동 중 시간 측정을 앱 안에서 끝낸다 (기본 시계 앱 대체)
2. 측정한 시간을 **기록으로 남겨** 훈련 시간 배분과 출석을 통계로 확인한다

## 2. 현재 사용 루틴 (as-is)

사용자가 설명한 실제 흐름입니다.

1. 헬스장 도착 → 타이머 시작 (전체 운동 시간 기준점)
2. 웜업
3. (때에 따라) 기술 연습
4. 근력 운동 전에 **타이머를 초기화하고 다시 시작** — 3분마다 다른 운동으로 넘어가는 기준으로 씀
5. 근력 운동 종료 후 피로저항 운동
6. 운동 종료

여기서 중요한 관찰이 하나 있습니다. 사용자는 서로 성격이 다른 **두 개의 시계**를 하나의 타이머로 돌려쓰고 있습니다.

| | A. 누적 시계 | B. 페이스 타이머 |
| --- | --- | --- |
| 목적 | "얼마나 했는가" 기록 | "다음 동작으로 넘어갈 때가 됐는가" 신호 |
| 대상 | 전체 세션, 구간별 시간 | 근력 운동의 3분 단위 |
| 리셋 | 절대 안 됨 (통계 원본) | 자주 함 (동작마다) |

기본 시계 앱에서는 B를 쓰기 위해 A를 버려야 했습니다. **타이머 탭의 핵심 설계 조건은 B의 리셋이 A의 누적을 지우지 않는 것입니다.**

## 3. 용어

| 용어 | 의미 |
| --- | --- |
| **세션 (Session)** | 헬스장 도착부터 운동 종료까지 한 번의 운동. 하루에 여러 개 가능 |
| **구간 (Segment)** | 세션 안의 훈련 종류 단위. 스트레칭 / 웜업 / 기술 연습 / 스트렝스 / 피로저항 |
| **랩 (Lap)** | 구간 안에서 페이스 타이머를 리셋할 때마다 끊기는 마디. 예: 스트렝스 구간의 3분 × 8회 |

## 4. 기능 요구사항

### FR-1. 타이머 탭 신설

- 탭바에 `타이머` 탭을 추가한다. 현재 3탭(웜업 / 피드백 버퍼 / 기술 라이브러리) → 4탭.
- 운동 중 젖은 손·장갑 상태에서도 누를 수 있도록 주요 버튼은 크고 화면 아래쪽에 배치한다.
- 타이머 탭 상단에서 `기록`과 `통계`로 넘어갈 수 있다 (결정 D4). 탭바는 4개로 유지한다.
- **누적 타이머와 페이스 타이머를 한 화면에 함께 보여준다** (결정 D5). 누적은 상단에 작게, 페이스 타이머는 화면 중앙에 크게.
- 진행 중 세션이 있으면 탭 아이콘 또는 라벨에 진행 표시를 준다. (탭을 벗어나 피드백을 적는 동안에도 돌아가고 있음을 알 수 있어야 함)

### FR-2. 세션 생애주기 — 두 개의 타이머

타이머는 두 층으로 돈다.

| | 누적 타이머 | 구간 타이머 |
| --- | --- | --- |
| 범위 | 세션 전체 | 현재 진행 중인 한 구간 |
| 시작 | `운동 시작` | 구간 시작 |
| 종료 | `운동 종료` | 구간 종료 |
| 개수 | 세션당 하나 | 한 번에 하나, 없을 수도 있음 |

흐름 (결정 D6)

1. `운동 시작` → **누적 타이머 ON + 첫 구간(웜업) 타이머 ON**
2. `웜업 종료` → 구간 타이머 OFF. **누적은 계속 돈다.**
3. 이 사이 — 구간 타이머가 꺼져 있고 누적만 도는 시간이 **휴식**이다
4. `스트렝스 시작` → 구간 타이머 ON
5. 반복
6. `운동 종료` → **누적 타이머 OFF.** 세션이 저장된다

- `일시정지` / `재개` → **누적과 구간이 모두 멈춘다.** 휴식과는 다르다. 휴식은 헬스장에 있는 시간이라 누적에 들어가고, 일시정지는 운동을 아예 벗어난 시간이라 누적에서도 빠진다.
- 앱을 벗어날 때 자동으로 멈추지 않는다 (결정 D9). 필요하면 사용자가 직접 일시정지를 누른다. 앱 안에서 피드백을 적는 동안에는 계속 돈다.
- `취소/삭제` → 잘못 시작한 세션을 기록에 남기지 않고 버릴 수 있다.
- 한 번에 진행 중인 세션은 하나만 존재한다.
- 종료를 잊고 앱을 닫은 세션이 있으면, 다음 진입 시 "아직 진행 중인 세션이 있어요 — 이어서 / 여기서 종료 / 버리기"를 물어본다.

### FR-3. 구간 전환

- 구간 종류: **스트레칭, 웜업, 기술 연습, 스트렝스, 피로저항** (휴식은 구간이 아니다 — FR-3.1)
- 구간은 **명시적으로 끄고 켠다.** 구간을 종료해도 다음 구간이 자동으로 시작되지 않는다. 그 간격이 휴식으로 측정되기 때문이다.
- 휴식 없이 바로 이어갈 때를 위해 "종료하고 바로 다음 구간 시작"도 한 번에 할 수 있게 한다.
- 순서는 권장 순서를 제시하지만 강제하지 않는다. 건너뛰기, 순서 바꾸기, **같은 구간에 다시 들어가기**가 모두 가능하다. (예: 스트렝스 → 기술 연습 → 스트렝스)
- 같은 구간에 여러 번 들어간 경우 통계에서는 합산한다.
- 한 순간에 활성 구간은 최대 하나다.
- 첫 구간은 웜업을 기본값으로 바로 시작한다. 다른 구간으로 시작하고 싶을 때의 처리는 결정 필요 (열린 질문 Q3).

### FR-3.1. 휴식 — 측정하되 조작하지 않는다

- **휴식은 버튼이 없다** (결정 D6). 구간 타이머가 꺼져 있고 누적 타이머만 도는 시간이 곧 휴식이다.
- 따라서 휴식은 저장하는 값이 아니라 **파생값**이다.
  `휴식 = 세션 순수 시간 − 모든 구간 시간의 합`
- 휴식 중인 화면에서는 경과한 휴식 시간을 보여준다. 다음 구간을 시작하면 그 휴식 구간이 닫힌다.
- 통계에서 휴식을 따로 보여줘 총 체류 시간 대비 실제 운동 비율을 알 수 있게 한다.

### FR-4. 페이스 타이머 (9분 = 한 운동)

기준 단위는 **9분**이다 (결정 D7). 한 운동을 3분씩 3세트 하므로, 9분이 곧 운동 하나다.

```
9분 랩 = 한 운동
├── 3분  1세트
├── 3분  2세트
└── 3분  3세트
```

- 큰 숫자는 현재 9분 랩의 경과 시간을 보여준다. 그 아래 3분 눈금 3개로 지금 몇 세트째인지 표시한다.
- **9분에 도달하면 자동으로 다음 랩(다음 운동)을 시작한다** (결정 D1). 손을 안 써도 계속 흘러간다.
- **자동 전환이 기본 동작이고, 수동 전환은 보조 수단이다.** 화면에서 이 위계가 드러나야 한다.
  - 다음 전환까지 남은 시간을 항상 보여준다. ("4:48 후 4번째 운동으로 자동 전환")
  - `지금 바로 다음 운동으로`는 9분을 다 채우지 않고 넘길 때만 쓰는 보조 동작이므로, `일시정지`·`구간 종료`와 같은 비중으로 나란히 두지 않는다.
  - 운동 중 손을 대는 경우는 셋뿐이어야 한다 — 일찍 넘기기, 일시정지, 구간 종료.
- 9분과 3분 길이는 사용자가 조정할 수 있게 한다. 기본값은 9분 / 3분 × 3세트.
- 랩 리셋은 **구간 누적과 세션 누적에 영향을 주지 않는다.** 9분 × 3운동을 돌려도 구간 누적은 27분으로 남는다.
- 3분 세트 경계에서도 신호를 줄지는 결정 필요 (열린 질문 Q2).
- 자동 반복을 멈추려면 구간을 종료하거나 세션을 일시정지한다.

### FR-5. 시간 계산 정확성 (필수)

- 경과 시간은 **틱 카운터를 누적하지 않는다.** `시작 시각 + 일시정지 구간` 기준으로 매번 계산한다. 화면 갱신용 타이머는 표시 전용이다.
- 앱이 백그라운드로 갔다가 돌아와도, 강제 종료 후 다시 켜도, 기기를 재부팅해도 경과 시간이 어긋나지 않는다.
- 진행 중 세션은 상태가 바뀔 때마다(시작·구간 전환·랩·일시정지) 즉시 디스크에 저장한다.
- 기기 시간이 수동으로 변경된 경우에도 음수 시간이 나오지 않도록 방어한다.

### FR-6. 백그라운드 동작 — 흘러가기만 하면 된다

- **알림은 앱이 화면에 떠 있을 때만 준다** (결정 D2). 로컬 알림 권한을 추가하지 않는다. 권한 요청 0개, `PrivacyInfo.xcprivacy`와 App Store 제출 메모를 그대로 유지한다.
- **화면이 꺼져 있는 동안 신호를 놓치는 것은 허용한다** (결정 D8). 요구사항은 "신호를 반드시 받는 것"이 아니라 **"시간이 정확히 흘러가 있는 것"**이다.
  - 따라서 화면 꺼짐 방지는 **필수가 아니라 선택 옵션**이다. 설정에서 켜고 끈다.
  - 복귀 시점에 실제 경과 시간을 그대로 반영한다. 백그라운드에 있던 동안 지나간 랩은 소급해서 기록한다.
- 백그라운드 오디오 세션으로 타이머를 계속 돌리는 방식은 쓰지 않는다 (App Review 리스크).
- 잠금화면 Live Activity / Dynamic Island
- 화면 꺼짐 방지 옵션는 v2로 미룬다.

### FR-7. 기록 저장

- 종료된 세션은 다음을 남긴다.
  - 세션 시작/종료 시각, 총 시간, 순수 운동 시간(일시정지 제외)
  - 구간 목록: 종류, 시작/종료 시각, 누적 시간
  - 구간별 랩 목록: 랩 번호, 랩 시간
  - 메모 (선택)
- 저장은 기존 방식을 따른다: 서버 없음, 기기 내 JSON 파일.
- 기록 목록 화면에서 과거 세션을 열어 구간 타임라인을 볼 수 있다.
- 잘못 기록된 세션을 **수정/삭제**할 수 있다. (종료를 늦게 눌러 시간이 부풀려진 경우가 실제로 자주 생김)

### FR-8. 통계

사용자가 요청한 두 가지 질문에 답해야 합니다 — "어떤 운동에 얼마나 투자하고 있나", "어느 날에 운동을 갔나".

- 기간 선택: 최근 7일 / 30일 / 90일 / 전체 (또는 이번 주 / 이번 달 / 전체)
- 요약 지표
  - 기간 내 총 운동 시간
  - 운동한 날 수
  - 세션당 평균 시간
  - 연속 운동 일수 / 최장 연속 일수
- 시간 배분
  - 구간별 누적 시간과 비율 (스트레칭 / 웜업 / 기술 연습 / 스트렝스 / 피로저항 + 휴식)
  - 총 체류 시간 대비 실제 운동 시간 비율 (휴식을 분리해 보여줌)
  - 주 단위 추이 (구간별 누적 막대)
- 출석
  - 캘린더 히트맵 — 운동한 날과 그 날의 운동량 농도
  - 날짜를 탭하면 그 날 세션 상세로 이동
- 데이터가 없을 때의 빈 상태 문구를 준비한다.
- 통계 계산은 UI와 분리된 순수 로직으로 둔다 (`FeedbackScoring`과 같은 위치). 테스트 대상.

### FR-9. 기존 기능과의 연계

이 앱의 핵심 가치는 "운동 직후의 감각을 붙잡는 것"입니다. 타이머는 그 순간을 정확히 알고 있는 유일한 기능이므로 연결 지점이 큽니다.

- **구간 종료 직후 피드백 추가 바로가기** — 감각이 가장 선명한 시점. 기록까지의 탭 수를 줄인다.
- **웜업 구간 시작 시 오늘의 웜업 러너 열기** — 웜업 세션 기능과 자연스럽게 이어진다.
- **기술 연습 구간에 기술 태깅** — 기술 라이브러리의 `Skill`을 붙이면 "기술별 투자 시간" 통계가 가능하다. README의 향후 아이디어 "기술별 통계 요약"과 맞물린다.
- 스트렝스 / 피로저항 구간은 피드백의 `체력 훈련` 범주와, 기술 연습 구간은 `기술 훈련` 범주와 대응된다. 용어를 일치시킨다.

## 5. 비기능 요구사항

- 서버·로그인·광고·추적 없음 유지. 네트워크 통신 없음.
- iOS 17.0+ 유지.
- 배터리: 화면이 보일 때만 화면 갱신 타이머를 돌리고, 백그라운드에서는 멈춘 뒤 복귀 시 재계산한다.
- 접근성: 경과 시간을 VoiceOver로 읽을 수 있어야 하고, 주요 버튼은 44pt 이상, 큰 글씨 대응.
- 기존 사용자의 데이터 마이그레이션 이슈 없음 (새 저장소 추가).

## 6. 데이터 모델 (제안)

```swift
enum TrainingPhaseKind: String, Codable, CaseIterable {
    case stretching        // 스트레칭
    case warmup            // 웜업
    case skillPractice     // 기술 연습
    case strength          // 스트렝스
    case fatigueResistance // 피로저항
    // 휴식은 케이스가 아니다. 구간 사이의 빈 시간으로 계산된다.
}

struct TrainingLap: Identifiable, Codable, Hashable {
    let id: UUID
    var index: Int          // 몇 번째 운동인가
    var duration: TimeInterval
    var targetDuration: TimeInterval  // 기본 9분
}

struct TrainingSegment: Identifiable, Codable, Hashable {
    let id: UUID
    var kind: TrainingPhaseKind
    var skillId: UUID?      // 기술 연습 구간에서만 사용
    var startedAt: Date
    var endedAt: Date?      // nil이면 아직 진행 중
    var laps: [TrainingLap]
}

struct PauseInterval: Codable, Hashable {
    var startedAt: Date
    var endedAt: Date?
}

struct WorkoutSession: Identifiable, Codable, Hashable {
    let id: UUID
    var startedAt: Date
    var endedAt: Date?
    var segments: [TrainingSegment]
    var pauses: [PauseInterval]
    var note: String
}
```

파생값 (저장하지 않는다)

```swift
extension WorkoutSession {
    /// 일시정지를 제외한 세션 순수 시간
    var activeDuration: TimeInterval { ... }
    /// 모든 구간 시간의 합
    var trainingDuration: TimeInterval { ... }
    /// 휴식 — 구간 타이머가 꺼져 있던 시간
    var restDuration: TimeInterval { activeDuration - trainingDuration }
}
```

## 7. 결정 사항

| # | 결정 | 내용 |
| --- | --- | --- |
| D1 | 랩 동작 | 목표 도달 시 **자동으로 다음 랩 시작**. 알림만 주고 타이머는 계속 돈다 |
| D2 | 백그라운드 알림 | **앱이 켜져 있을 때만.** 로컬 알림 권한을 추가하지 않는다 |
| D4 | 통계 위치 | **타이머 탭 안 하위 화면.** 탭바는 4개 유지 |
| D5 | 두 시계 | 누적 타이머와 페이스 타이머를 **한 화면에 동시 표시** |
| D6 | 휴식 | **버튼 없음.** 구간 타이머가 꺼져 있고 누적만 도는 시간 = 휴식. 파생값으로 계산 |
| D7 | 페이스 단위 | **9분** (3분 × 3세트 = 운동 하나). 3분에서 9분으로 변경 |
| D8 | 화면 꺼짐 | 신호를 놓쳐도 괜찮다. **시간이 흘러가 있기만 하면 됨.** 화면 꺼짐 방지는 선택 옵션 |
| D9 | 자동 일시정지 | **지원하지 않는다.** 앱을 벗어나기 전 사용자가 직접 멈춘다 |
| D10 | 휴식 UI | **휴식은 버튼 없이 상태로만 표시.** 버튼은 일시정지만 둔다 |

> D3(휴식을 별도 구간으로 기록)은 D6으로 대체됐다. 버튼으로 고르는 구간이 아니라 타이머 사이의 간격으로 측정한다.

## 9. 범위 구분

### MVP

- 타이머 탭, 운동 시작 / 일시정지 / 재개 / 운동 종료
- 5종 구간 명시적 시작/종료, 구간별 누적 시간
- 휴식 자동 측정 (구간 사이 간격)
- 페이스 타이머 (9분 = 3분 × 3세트, 자동 반복)
- 누적 + 페이스 동시 표시
- 세션 기록 저장 및 목록, 세션 상세 타임라인
- 앱 종료·재부팅 후 진행 중 세션 복구
- 기본 통계 — 기간 총 시간, 운동한 날 수, 구간별 비율, 캘린더 히트맵 (타이머 탭 하위 화면)

### v2 이후

- 잠금화면 Live Activity / Dynamic Island
- 화면 꺼짐 방지 옵션
- 기술 태깅 기반 기술별 투자 시간 통계
- 구간 종료 후 피드백 추가 바로가기 심화 (구간 정보가 붙은 피드백)
- 세션 시간 수동 보정 편집
- 주간 훈련 회고 (README 향후 아이디어와 통합)
- 애플워치 / HealthKit 연동
