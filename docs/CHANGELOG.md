# Changelog

Feedback Buffer의 배포별 변경 내역을 기록합니다.

## 1.1 - 예정

### Added
- 타이머 탭이 생겼어요. 운동 시간을 앱 안에서 재고 기록으로 남길 수 있어요.
- 구간을 누르면 운동이 시작돼요. 스트레칭, 웜업, 기술 연습, 스트렝스, 피로저항 중에서 고르면 전체 누적 타이머도 함께 켜져요.
- 구간을 끝내고 다음 구간을 시작하기 전까지의 시간은 휴식으로 자동 기록돼요. 따로 누를 버튼이 없어요.
- 스트렝스 구간에서는 9분 단위로 다음 운동으로 저절로 넘어가요. 3분씩 3세트가 한 운동이고, 세트가 바뀌면 짧게 한 번, 운동이 바뀌면 짧게 세 번 진동해요.
- 9분을 다 채우지 않고 넘기고 싶으면 "지금 바로 다음 운동으로"를 누르면 돼요. 넘겨도 구간 누적 시간은 줄지 않아요.
- 잠깐 운동을 벗어날 때는 일시정지를 누를 수 있어요. 휴식과 달리 누적 시간에서도 빠져요.
- 통계에서 어떤 운동에 얼마나 시간을 쓰고 있는지, 어느 날에 운동을 갔는지 볼 수 있어요. 기간은 7일, 30일, 90일, 전체 중에 고를 수 있어요.
- 기록은 하루 단위로 묶여요. 하루에 두 번 운동해도 "운동한 날"은 하루로 쳐요.
- 휴식 중에 바로 피드백을 적을 수 있어요. 감각이 가장 선명한 순간을 놓치지 않게요.
- 기술 라이브러리에 검색을 추가했어요. 기술 이름으로 빠르게 찾을 수 있어요.
- 기술 라이브러리의 기술 상세 화면에 보관함 탭이 추가됐어요. 보관한 피드백을 다시 꺼내 연습할 수 있어요.
- 기술 라이브러리 카드에 보관된 피드백 개수도 함께 표시돼요. 활성은 강조색, 보관은 초록색으로 구분돼요.
- 웜업 루틴을 여러 개 만들고 전환할 수 있어요. 루틴 이름과 항목 목록만 입력하면 한 번에 만들어져요.
- 웜업 화면에 "오늘의 웜업 시작" 버튼이 추가됐어요. 항목을 한 장씩 카드로 보여주며 따라갈 수 있어요.

- 타이머를 켜지 못한 날의 운동을 기록에 직접 추가할 수 있어요. 날짜와 구간별 시간만 적으면 돼요.
- 이미 남은 기록의 구간 시간을 고칠 수 있어요. 잘못 눌렀거나 시간이 어긋났을 때 쓰면 돼요.
- 구간이 진행 중일 때도 오른쪽 위 버튼으로 바로 피드백을 적을 수 있어요.

### Fixed
- 피드백 카드 우선순위 점수 정보 팝오버의 텍스트가 잘려 보이던 문제를 수정했어요.

### Changed
- 타이머가 돌고 있으면 탭에 표시가 붙어요. 피드백을 적으러 다른 탭에 가 있어도 운동이 진행 중인 걸 알 수 있어요.
- 앱을 끄거나 화면이 꺼져 있어도 시간은 그대로 흘러가요. 다시 열면 그동안 지나간 만큼이 반영돼 있어요.
- 운동을 끝내지 않고 앱을 닫았다면 다시 열 때 이어서 할지, 마지막 시점까지만 저장할지, 버릴지 고를 수 있어요.
- 웜업 화면이 지금 고른 루틴 이름을 카드에 보여줘요. 어떤 루틴을 하고 있는지 한눈에 알 수 있어요.
- 웜업 화면에서 항목 목록을 뺐어요. 시작을 누르면 한 장씩 보이니까, 탭에서는 시작할지 말지만 정하면 돼요.
- 건너뛴 항목이 있어도 끝까지 진행했다면 "오늘의 웜업 완료!"로 표시돼요. 몇 개를 하고 몇 개를 건너뛰었는지도 함께 보여줘요.
- 오늘 웜업을 끝낸 뒤에도 다시 시작할 수 있어요. 하루에 두 번 하거나 건너뛴 항목을 마저 할 때 쓰면 돼요.
- 기술 카드 하단에 마지막 연습 시점이 표시돼요. 얼마나 오래됐는지 한눈에 알 수 있어요.
- 피드백이 비어 있을 때 기술 라이브러리로 바로 이동하는 버튼이 생겼어요.
- 피드백 점수 옆 아이콘을 탭하면 점수 산정 방식과 단계별 색상 의미를 확인할 수 있어요.
- 피드백 버퍼의 범주 필터를 "전체 / 체력 훈련 / 기술 훈련" 단일 선택으로 바꿨어요.
- 카드의 "미해결" 버튼을 "연습했어요"로 바꿨어요. 누르면 연습 횟수가 1 늘어나고 마지막 연습일이 오늘로 갱신돼요.
- 기술 카드의 활성/보관 카운트 옆에 작은 아이콘이 붙었어요. 색상이 잘 안 보이는 환경에서도 어떤 상태인지 바로 알 수 있어요.
- 피드백이 새 피드백 → 연습 시작 → 적응 중 → 보관 흐름을 따라가도록 정리했어요.
- 웜업 세션 목록의 이름 변경/항목 수정/삭제를 행 우측 점 세 개 메뉴 한 곳에서 할 수 있어요.
